Works with Antigravity CLI, Claude Code, Claude Desktop, Codex, Cursor CLI, Cursor Desktop, DeepSeek Harness, OpenCode, pi, WorkBuddy (China and international), and ZCode. More Agent Harnesses coming soon.

There’s also koto CLI.<br>
Copy a session. Just ask.

> You: Use koto to copy this session to pi.
>
> Agent Harness: Copied 5 turns to pi.<br>
> Open the copied session in pi with this command:<br>
> `cd <project> && pi --session <new-session-id>`
