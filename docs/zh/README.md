# koto

[English](../../README.md) · [简体中文](README.md) · [繁體中文](../zh-TW/README.md) · [日本語](../ja/README.md) · [Deutsch](../de/README.md)

**换个 Agent Harness，接着聊。**

在 Claude Code、Codex、Cursor 等 Agent Harness 之间复制会话。

保留对话历史，在不同 Agent Harness 中分叉续聊，比较后续进展。

[下载](https://github.com/Seanium/koto/releases/latest) · [网站](https://kotoai.site/)

支持 Antigravity CLI、Claude Code、Claude Desktop、Codex、Cursor CLI、Cursor Desktop、DeepSeek Harness、OpenCode、pi、WorkBuddy 国内版与国际版，以及 ZCode。还有更多，即将到来。

还有 koto CLI，<br>
复制，一句话的事。

> 你：用 koto 复制当前会话到 pi
>
> Agent Harness：已复制 5 轮到 pi。<br>
> 用这条命令打开 pi 中复制好的会话：<br>
> `cd <项目路径> && pi --session <新会话ID>`
