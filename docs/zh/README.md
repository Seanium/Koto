**换个 Agent，接着聊。**

把会话复制到另一个 Agent。用会话树和 diff 对比会话。

支持 Claude Code（含 Desktop Code）、Codex、pi、DeepSeek Harness、Antigravity CLI 和 OpenCode。还有更多，即将到来。

还有 koto CLI，<br>
复制，一句话的事。

> 你：用 koto 复制当前会话到 pi
>
> Agent：已复制 5 轮到 pi。<br>
> 用这条命令打开 pi 中复制好的会话：<br>
> `cd <项目路径> && pi --session <新会话ID>`
