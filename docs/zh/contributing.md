# 参与贡献

[English](../../CONTRIBUTING.md) · [简体中文](contributing.md) · [繁體中文](../zh-TW/contributing.md) · [日本語](../ja/contributing.md) · [Deutsch](../de/contributing.md)

说明解决了什么问题、改了什么，以及实际测试结果。修改连接器时，附上原生格式和 Agent Harness 版本。

按[开发指南](development.md)构建和测试。使用合成数据与新建的临时会话，不提交个人对话、凭据、数据库或测试日志。

按改动范围检查：

- **界面：**浅深色、窄窗口、键盘操作和较长译文。
- **复制：**内容选择、同 Agent Harness 复制、重复复制、附件与路径冲突，来源必须保持不变。
- **原生代码：**在受影响的平台构建并运行，分别说明编译、安装和界面的测试结果。

贡献遵循项目的 MIT 许可证。修改依赖或素材时，保留第三方声明。
