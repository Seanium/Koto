# Mitwirken

[English](../../CONTRIBUTING.md) · [简体中文](../zh/contributing.md) · [繁體中文](../zh-TW/contributing.md) · [日本語](../ja/contributing.md) · [Deutsch](contributing.md)

Das Problem, die Änderung und die tatsächlich ausgeführten Tests beschreiben. Bei Änderungen an Konnektoren das native Format und die Agent Harness-Version angeben.

Nach der [Entwicklungsanleitung](development.md) bauen und testen. Synthetische Daten und neue temporäre Sitzungen verwenden; persönliche Gespräche, Zugangsdaten, Datenbanken und Testprotokolle nicht einchecken.

Die betroffenen Bereiche prüfen:

- **Oberfläche:** helles und dunkles Erscheinungsbild, schmale Fenster, Tastaturbedienung und lange Übersetzungen.
- **Kopieren:** Inhaltsauswahl, Kopien zum selben Agent Harness, wiederholte Kopien, Anhänge und Pfadkonflikte. Die Quelle bleibt unverändert.
- **Nativer Code:** auf dem betroffenen Betriebssystem bauen und ausführen. Ergebnisse für Kompilierung, Installation und GUI getrennt angeben.

Beiträge stehen unter der MIT-Lizenz des Projekts. Bei Änderungen an Abhängigkeiten oder Assets die Drittanbieterhinweise erhalten.
