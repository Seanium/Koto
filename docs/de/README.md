Für Antigravity CLI, Claude Code, Claude Desktop, Codex, Cursor CLI, Cursor Desktop, DeepSeek Harness, OpenCode, pi, WorkBuddy (China und international) und ZCode. Weitere Agent Harnesses folgen bald.

Auch mit koto CLI.<br>
Kopieren. Ein Satz genügt.

> Du: Kopiere dieses Gespräch mit koto nach pi.
>
> Agent Harness: 5 Runden nach pi kopiert.<br>
> Öffne die kopierte Sitzung in pi mit diesem Befehl:<br>
> `cd <Projektpfad> && pi --session <neue-Sitzungs-ID>`
