**Agent Harness を変えて、対話の続きを。**

対話を別の Agent Harness にコピー。ツリーと diff でセッションを比較。

Antigravity CLI、Claude Code、Claude Desktop、Codex、Cursor CLI、Cursor Desktop、DeepSeek Harness、OpenCode、pi、WorkBuddy（中国版・国際版）、ZCode に対応。さらに多くの Agent Harness に近日対応。

koto CLI も。<br>
コピーは、ひと言で。

> あなた：koto で今の対話を pi にコピーして。
>
> Agent Harness：5 ターンを pi にコピーしました。<br>
> コピーした対話を pi で開くには、このコマンドを使ってください：<br>
> `cd <プロジェクトパス> && pi --session <新しいセッションID>`
