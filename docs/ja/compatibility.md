# セッション形式と添付ファイル

[English](../compatibility.md) · [简体中文](../zh/compatibility.md) · [繁體中文](../zh-TW/compatibility.md) · [日本語](compatibility.md) · [Deutsch](../de/compatibility.md)

表は対応する保存形式を示します。Agent の更新で形式が変わる場合があります。添付ファイルの認識はコピー先のモデルに依存します。

| Agent | 読み込み | コピー作成 |
| --- | --- | --- |
| Claude Code / Desktop Code | JSONL とネイティブの分岐 | 新しい UUID とネイティブ JSONL |
| pi | v3 JSONL ツリー | 新しい ID・親チェーンを持つセッション |
| Codex | rollout JSONL / zstd | 新しいネイティブ rollout を作成し、app-server で読み込み検証 |
| DeepSeek Harness | v4 JSONL / zstd | 新しいディレクトリとネイティブ圧縮ログ |
| Antigravity CLI | SQLite と protobuf 軌跡 | 新しい対話データベースと要約エントリー |

コピーは必ず新しいネイティブセッションを作成し、保存先に既存のパスがある場合は拒否します。コピー先の Agent が自身の設定を読み込みます。元のシステム・開発者・環境・設定・権限の文脈はコピーしません。ツールや推論に互換性のあるネイティブ表現がない場合は、読めるテキストへ変換することがあります。

## 添付ファイル

| 素材 | Claude Code | pi | Codex | DeepSeek Harness | Antigravity CLI |
| --- | --- | --- | --- | --- | --- |
| PNG、JPEG、GIF、WebP | ネイティブ画像 | ネイティブ画像 | ネイティブ画像 | ネイティブ画像添付 | ネイティブ Media |
| PDF、UTF-8 テキスト | ネイティブ文書 | 完全なファイル | 完全なファイル | ネイティブファイル添付 | ネイティブ Media |
| 音声 | 完全なファイル | 完全なファイル | ネイティブ音声 | ネイティブファイル添付 | ネイティブ Media |
| DOCX、ZIP、JSON、その他のバイナリ | 完全なファイル | 完全なファイル | 完全なファイル | ネイティブファイル添付 | ネイティブ Media |

ロールやコピー先がファイルの埋め込みに対応しない場合は、新しいセッションの添付ディレクトリに完全なバイト列を保存し、ファイル参照を追加します。ツール記録をテキストに変換した場合も、ツール結果の添付は保持します。

- 添付は、認識できるネイティブ添付元から読み込みます。メッセージ中の任意のパスは読み込みません。
- koto 管理のファイル参照を再コピーする際は、ディレクトリ、実パス、サイズ、SHA-256 を検証します。外部シンボリックリンク、パストラバーサル、改変されたファイルは拒否します。
- 見つからない blob は報告します。リモート URI は参照のままで、オフライン保存用にダウンロードしません。
- 個別プレビューは 25 MiB、添付読み込みは 256 MiB が上限です。上限によってファイルを途中までのテキスト要約に変換することはありません。

## 検証の範囲

標準テストは合成 fixture と使い捨ての Agent ルートを使います。対応 Agent 間のコピー、同じ Agent へのコピー、明示的な選択、繰り返しの新規作成、パスの競合、添付、再コピー時の整合性を検証します。

ネイティブ環境での対話継続テストは、インストール済みの Agent、モデル、プロバイダーに依存し、標準テストとは別に実行します。すべてのモデル、形式とロールの組み合わせ、デスクトップ環境を網羅しているわけではありません。
