# セッション形式と添付ファイル

[English](../compatibility.md) · [简体中文](../zh/compatibility.md) · [繁體中文](../zh-TW/compatibility.md) · [日本語](compatibility.md) · [Deutsch](../de/compatibility.md)

表は対応する保存形式を示します。Agent Harness の更新で形式が変わる場合があります。添付ファイルの認識はコピー先のモデルに依存します。

| Agent Harness | 読み込み | コピー作成 |
| --- | --- | --- |
| Claude Code / Claude Desktop（Code） | JSONL とネイティブの分岐 | 新しい UUID とネイティブ JSONL |
| pi | v3 JSONL ツリー | 新しい ID・親チェーンを持つセッション |
| Codex | rollout JSONL / zstd | 新しいネイティブ rollout を作成し、app-server で読み込み検証 |
| DeepSeek Harness | v4 JSONL / zstd | 新しいディレクトリとネイティブ圧縮ログ |
| Antigravity CLI | SQLite と protobuf 軌跡 | 新しい対話データベースと要約エントリー |
| OpenCode | SQLite v1（`session`、`message`、`part`） | ネイティブ DB に新しいセッション行を作成 |
| Cursor CLI | セッションごとの SQLite `store.db` | 新しいネイティブ CLI セッション |
| Cursor Desktop | `state.vscdb` の会話・メッセージ blob | 新しい IDE 対話。App で開く |
| WorkBuddy / WorkBuddy AI | 中国版・国際版別のルート、SQLite 索引と JSONL | 既存のネイティブアカウントに新規作成 |
| ZCode | App / CLI 共通の SQLite 履歴と App タスク索引 | 新規セッションと対応するタスク項目 |

OpenCode 1.19.3 の v1 形式に対応しています。v2 の保存形式は明示的に拒否します。コピー先には OpenCode CLI と既定モデルの設定が必要です。続きの対話にはコピー先のモデルを使います。

コピーは新しいネイティブセッションを作成し、既存のセッション ID や個別ファイルを上書きしません。コピー先の Agent Harness が自身の設定を読み込みます。元のシステム・開発者・環境・設定・権限の文脈はコピーしません。ツールや推論に互換性のあるネイティブ表現がない場合は、読めるテキストへ変換することがあります。

Cursor Desktop と CLI は保存先と継続方法が異なります。ZCode は製品版のネイティブ Agent Harness に対応し、Preview や ZCode から起動する外部 Agent Harness は対象外です。WorkBuddy 中国版と国際版は別のコピー先です。履歴のアカウント表示は、継続時の認証情報を変更しません。

Claude Desktop のローカル Code セッションは読み取りと新規コピーに対応しています。既存のローカル Cowork ログは読み取り、対応するコピー先へコピーできますが、Cowork タスクの新規作成には対応していません。クラウドの Chat 履歴はローカルスキャンの対象外です。

コピーした Code セッションが Claude Desktop に表示されない場合は、アプリを再起動して会話一覧を更新してください。

## 添付ファイル

| 素材 | Claude Code | pi | Codex | DeepSeek Harness | Antigravity CLI | OpenCode |
| --- | --- | --- | --- | --- | --- | --- |
| PNG、JPEG、GIF、WebP | ネイティブ画像 | ネイティブ画像 | ネイティブ画像 | ネイティブ画像添付 | ネイティブ Media | ネイティブファイル |
| PDF、UTF-8 テキスト | ネイティブ文書 | 完全なファイル | 完全なファイル | ネイティブファイル添付 | ネイティブ Media | ネイティブファイル |
| 音声 | 完全なファイル | 完全なファイル | ネイティブ音声 | ネイティブファイル添付 | ネイティブ Media | ネイティブファイル |
| DOCX、ZIP、JSON、その他のバイナリ | 完全なファイル | 完全なファイル | 完全なファイル | ネイティブファイル添付 | ネイティブ Media | ネイティブファイル |

| 追加の Agent Harness | 添付の形式 |
| --- | --- |
| Cursor CLI / Cursor Desktop | ネイティブ画像、完全なファイルまたはファイル参照 |
| WorkBuddy / WorkBuddy AI | ネイティブ画像とユーザーファイル参照。ツールのファイルには検証済み参照を使用 |
| ZCode | ネイティブメディアとコピー先セッション内の完全なファイル |

ロールやコピー先がファイルの埋め込みに対応しない場合は、新しいセッションの添付ディレクトリに完全なバイト列を保存し、ファイル参照を追加します。ツール記録をテキストに変換した場合も、ツール結果の添付は保持します。

- 添付は、認識できるネイティブ添付元から読み込みます。メッセージ中の任意のパスは読み込みません。
- koto 管理のファイル参照を再コピーする際は、ディレクトリ、実パス、サイズ、SHA-256 を検証します。外部シンボリックリンク、パストラバーサル、改変されたファイルは拒否します。
- 見つからない blob は報告します。リモート URI は参照のままで、オフライン保存用にダウンロードしません。
- 元の会話にテキスト添付の一部しか保存されていない場合は、保存済みの内容をコピーし、一部であることを明記します。ディスク上の現在のファイルから不足分を補うことはありません。
- 個別プレビューは 25 MiB、添付読み込みは 256 MiB が上限です。上限によってファイルを途中までのテキスト要約に変換することはありません。

## 検証の範囲

標準テストは合成 fixture と使い捨ての Agent Harness ルートを使います。対応 Agent Harness 間のコピー、同じ Agent Harness へのコピー、明示的な選択、繰り返しの新規作成、パスの競合、添付、再コピー時の整合性を検証します。

ネイティブ環境での対話継続テストは、インストール済みの Agent Harness、モデル、プロバイダーに依存し、標準テストとは別に実行します。すべてのモデル、形式とロールの組み合わせ、デスクトップ環境を網羅しているわけではありません。
