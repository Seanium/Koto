# 貢献について

[English](../../CONTRIBUTING.md) · [简体中文](../zh/contributing.md) · [繁體中文](../zh-TW/contributing.md) · [日本語](contributing.md) · [Deutsch](../de/contributing.md)

解決する問題、変更内容、実施したテストを説明してください。コネクターの変更には、確認したネイティブ形式と Agent Harness のバージョンを添えてください。

[開発ガイド](development.md)に従ってビルド・テストします。合成データと新しい一時セッションを使い、個人の対話、認証情報、データベース、テストログはコミットしないでください。

変更した部分を確認してください。

- **UI：**ライト・ダーク、狭いウィンドウ、キーボード操作、長い翻訳。
- **コピー：**内容の選択、同じ Agent Harness へのコピー、繰り返しのコピー、添付ファイル、パス競合。コピー元は変更しません。
- **ネイティブコード：**対象 OS でビルド・実行し、コンパイル、インストール、GUI の結果を分けて報告します。

貢献にはプロジェクトの MIT ライセンスが適用されます。依存関係や素材を変える際は第三者の権利表示を保ってください。
