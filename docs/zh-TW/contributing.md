# 參與貢獻

[English](../../CONTRIBUTING.md) · [简体中文](../zh/contributing.md) · [繁體中文](contributing.md) · [日本語](../ja/contributing.md) · [Deutsch](../de/contributing.md)

說明解決了什麼問題、改了什麼，以及實際測試結果。修改連接器時，附上原生格式與 Agent 版本。

依[開發指南](development.md)建置及測試。使用合成資料與新建的暫存工作階段，不提交個人對話、憑證、資料庫或測試日誌。

依改動範圍檢查：

- **介面：**淺深色、窄視窗、鍵盤操作與較長譯文。
- **複製：**內容選取、同 Agent 複製、重複複製、附件與路徑衝突，來源必須保持不變。
- **原生程式碼：**在受影響的平台建置並執行，分別說明編譯、安裝與介面的測試結果。

貢獻遵循專案的 MIT 授權條款。修改相依套件或素材時，保留第三方聲明。
