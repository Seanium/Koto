支援 Claude Code（含 Desktop Code）、Codex、pi、DeepSeek Harness 和 Antigravity CLI。還有更多，即將到來。

還有 koto CLI，<br>
複製，一句話的事。

> 你：用 koto 複製目前的對話到 pi
>
> Agent：已複製 5 輪到 pi。<br>
> 用這個指令開啟 pi 中複製好的對話：<br>
> `cd <專案路徑> && pi --session <新工作階段ID>`
